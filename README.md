
# Ironcore Fitness — Business Website

A modern, responsive business website for Ironcore Fitness, built as part of the ApnoAI Internship – Project First Client.

## About the Project

Ironcore Fitness is a fictional fitness brand website designed to provide visitors with information about gym facilities, training programs, membership plans, and contact details.

The website focuses on a clean professional design, easy navigation, and a responsive user experience across different devices.

## Features

- Professional business website design
- Responsive layout for mobile, tablet, and desktop
- Mobile-friendly navigation menu
- Attractive hero section
- About section
- Fitness programs section
- Why Choose Us section
- Membership plans with pricing
- Contact information
- Interactive enquiry form
- Form validation and success message
- Smooth scrolling navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
